# Public edition

- Independent source snapshot with a fresh Git history.
- No production database, uploads, runtime state, credentials, user roster or deployment identifiers are included.
- Customer branding, private documents and account-specific migration/repair payloads have been removed where present.
- Example organization labels and seeded assessments are explicitly fictional. Test-only contact values are fixtures, never a directory of real contacts.
- Numeric scenario values and prefilled assessment content are examples for adaptation, not an organization assessment.
- Local environment files, logs, databases and build caches are excluded by `.gitignore`.
- Third-party attribution and licenses are retained; names in those notices identify upstream copyright holders, not application users.

Before deploying your own copy, configure authentication and storage for your environment and keep any new personal data outside the source repository.
